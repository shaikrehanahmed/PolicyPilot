# Official Source Document Snapshots

This directory holds cached snapshots of official government scheme guidelines, gazettes, and circulars used by the RAG knowledge ingestion engine in Phase 2.

Using cached verified snapshots ensures:
1. Complete reproducibility during live presentations and evaluations.
2. Protection against government portal downtime, network latency, or anti-bot blocks.
3. Accurate content hashing (`content_hash`) to track document freshness and detect policy updates.
